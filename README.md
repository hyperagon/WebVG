# Torani
### vecTOR ANImator

An [SVG](https://en.wikipedia.org/wiki/SVG) editor inspired by [Glaxnimate](https://glaxnimate.org/) and the [Wick Editor](https://www.wickeditor.com/#/).

Features:
- Offline
- No Dependencies
- Shapes (Rectangle, Ellipse, Text)
- Line
- Line-rail (Ctrl)
- Brush
- Brush-rail (Ctrl)
- Re-order Objects
- Groups
